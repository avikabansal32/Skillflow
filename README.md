# SkillFlow 🎯

### Learn with direction. Plan with purpose.

SkillFlow is a personalized learning and productivity web application designed to help students turn their learning goals into actionable plans.

It combines personalized learning roadmaps, daily scheduling, and adaptive rescheduling to help students make consistent progress toward their goals—even when their schedules change.

## 💡 The Problem

Students often struggle with three questions:

- What should I learn next?
- How can I fit learning into my daily schedule?
- What should I do when I fall behind?

Learning roadmaps provide direction, while productivity planners help manage time. SkillFlow connects the two into one experience.

## 🚀 Our Solution

SkillFlow helps students identify what they need to learn, organize their learning journey, and adapt their schedules as their priorities and availability change.

Instead of treating an unfinished task as a failed plan, SkillFlow helps students reorganize their remaining work and continue making progress.

## ✨ Key Features

- **Personalized Learning Roadmaps:** Organize learning goals into structured stages and manageable tasks.
- **Smart Daily Scheduling:** Allocate learning tasks according to available time.
- **Adaptive Rescheduling:** Reorganize unfinished tasks when plans change.
- **Progress Tracking:** Monitor completed tasks, pending work, and overall progress.
- **Skill-Gap Awareness:** Identify skills that still need to be developed.
- **Student-Friendly Interface:** Navigate learning goals, schedules, and progress through a clean dashboard.

*Feature availability depends on the current implementation. Features not yet implemented should be marked as planned rather than presented as completed.*

## 🧠 What Makes SkillFlow Different?

SkillFlow connects learning progress with time management.

A learning roadmap provides the direction. The scheduler turns that direction into daily actions. Progress tracking informs the next schedule, allowing the application to adapt when a student misses a session or changes their availability.

The goal is to make learning plans more practical and flexible.

## 🛠️ Tech Stack

- HTML5
- CSS3
- JavaScript
- Browser Local Storage
- JSON for sample learning-path data

## 🏗️ Project Architecture

The application is organized into separate modules for onboarding, roadmap generation, scheduling, progress tracking, and local data storage.

This modular approach makes the application easier to maintain, test, and extend.

## ⚙️ Getting Started

### Prerequisites

- A modern web browser
- Git
- A code editor such as Visual Studio Code

### Installation

1. Clone the repository:

   ```bash
   git clone https://github.com/YOUR-USERNAME/skillflow.git
   ```

2. Navigate to the project directory:

   ```bash
   cd skillflow
   ```

3. Open the project in your preferred code editor.

4. Launch `index.html` using a local development server.

   If you use Visual Studio Code, you can use the Live Server extension.

5. Complete the onboarding form and explore the available features.

Replace `YOUR-USERNAME` with your actual GitHub username before publishing these instructions.

## 🗺️ Example Use Case

A first-year engineering student wants to learn machine learning.

They already know basic Python and can dedicate one hour per day to learning.

SkillFlow uses their preferences to present an appropriate learning roadmap and organize its tasks into a daily schedule.

If the student misses a planned session, they can request a revised schedule based on their remaining tasks and available time.
